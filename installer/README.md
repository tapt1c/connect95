# Установщик ConnectXP 1.0

Комплект использует **Inno Setup 5.6.1 Unicode (u), с ISPP**. Эта версия
поддерживает Windows XP. В ANSI-редакторе 5.6.1 (a) русский текст зависит
от системной кодировки; используйте Unicode-выпуск, чтобы избежать искажения
кириллицы, в том числе в именах пользователей и путях.

## Сборка

Распакуйте комплект, откройте `connectxp.iss` и нажмите Compile. Либо:

```bat
"C:\Program Files\Inno Setup 5\ISCC.exe" connectxp.iss
```

`uninstall.iss` подключается автоматически; отдельно его компилировать не нужно.
Оба ISS-файла и `licenses\license_*.txt` сохранены в **UTF-8 с BOM, CRLF**.
Редактируйте их в этой кодировке. Настройки приложения в `settings.ini`
используют UTF-16; это отдельный файл, который создаёт сама программа.

В отдельном комплекте рядом со скриптом находятся `ConnectXP.exe`,
`ConnectXP.ico`, `THIRD-PARTY-NOTICES.txt`, `wizardconn.bmp`, `miniconn.bmp`,
`uninstall.iss` и папка `licenses`. Других файлов не требуется.
В репозитории EXE и уведомления компонентов берутся из `..\releases`,
иконка — из `..\resources\connectxp.ico`.

Для другой папки с EXE допустим `/DPayloadDir="C:\ConnectXP"`, для точного
файла — `/DPayloadFile="C:\ConnectXP\ConnectXP.exe"`. Также доступны
`/DIconFile="..."` и `/DNoticesFile="..."`.
Результат: `output\ConnectXP-1.0.0-Setup-x86.exe`.

## Установка и удаление

- Папка фиксирована: `{win}\ConnectXP`, обычно **C:\Windows\ConnectXP**.
  Старый путь установки не подхватывается. Требуются права администратора.
- Страницы выбора папки, группы меню, дополнительных задач и подтверждения
  параметров пропущены. Приветствие и условия использования сохранены.
- Ярлыки в общем меню «Пуск» и на общем рабочем столе создаются автоматически.
  Автозапуск включается по желанию в самой программе.
- Приложение запускается с правами обычного пользователя и хранит собственные
  данные каждого пользователя в **%LOCALAPPDATA%\ConnectXP**: ключи,
  сопряжения, история и `settings.ini` с языком, именем ПК и параметрами.
  Язык по умолчанию определяется по языку интерфейса Windows.
- Старые хранилища не читаются и не импортируются. После обновления потребуется
  заново сопрячь телефон. Старые пользовательские файлы не удаляются.
- При удалении профиль сохраняется по умолчанию. Отдельная отметка очищает
  известные файлы профиля только указанной в диалоге учётной записи.
  Неизвестные файлы и подпапки сохраняются. Тихое удаление сохраняет профиль.
- Полученные файлы в «Мои документы\ConnectXP» не удаляются. Запись автозапуска
  текущей учётной записи удаляется только если она указывает на удаляемый EXE.
- Перед установкой и удалением выйдите из ConnectXP через меню трея.
- Нет установки внешних DLL, .NET, VC++ Runtime, COM или Active Setup,
  автоматических изменений брандмауэра или настроек других пользователей.

Используются предоставленные автором картинки `wizardconn.bmp` (164×314),
`miniconn.bmp` (48×48) и авторская иконка ConnectXP. Тексты на русском и
английском можно править в `[Messages]` и `licenses\license_*.txt`.
Условия использования и лицензии компонентов устанавливаются рядом с EXE;
отдельная лицензия на исходный код этими условиями не устанавливается.

## Проверка

Проверяются комплектность, UTF-8 BOM/CRLF, контрольные суммы и синтаксис
на временной копии через 64-битный компилятор Inno Setup 7.1 без вывода EXE.
Только в проверочной копии минимум ОС меняется на 6.1, а `CreateCustomForm`
получает сигнатуру Inno 7. Публикуемые скрипты сохраняют API Inno 5.6.1 Unicode.
Полная сборка и запуск установщика через Inno Setup 5.6.1 на XP не подтверждены:
32-битный компилятор не запускается через Wine в этой облачной среде.
Готовый Setup EXE в комплект не включён.
