# Установщик ConnectXP 1.0

Скрипт основан на предоставленном шаблоне CopilotXP: сохранены двуязычное
приветствие, белая страница условий использования и выбор очистки данных при
удалении. Используются предоставленные `wizardconn.bmp` (164×314) и
`miniconn.bmp` (48×48). Значок установщика — авторская иконка ConnectXP.

## Сборка в Windows

Нужен **Inno Setup 5.6.1 ANSI с препроцессором ISPP**. Эта версия создаёт
установщик, совместимый с Windows XP. Современный Inno Setup 6 для этого
комплекта не используется.

Откройте `connectxp_cp1251.iss` в IDE и нажмите Compile или выполните:

```bat
"C:\Program Files\Inno Setup 5\ISCC.exe" connectxp_cp1251.iss
```

В репозитории EXE берётся из `..\releases\ConnectXP-1.0.0-x86.exe`,
иконка из `..\resources\connectxp.ico`, уведомления о лицензиях компонентов —
из `..\releases\THIRD-PARTY-NOTICES.txt`.

В отдельном комплекте положите рядом со скриптом `ConnectXP.exe`,
`ConnectXP.ico`, `THIRD-PARTY-NOTICES.txt`, обе BMP-картинки, `uninstall.iss`
и папку `licenses`. Соберите так:

```bat
ISCC.exe connectxp_cp1251.iss
```

Можно указать другую папку с EXE через `/DPayloadDir="C:\ConnectXP"` или
точный файл через `/DPayloadFile="C:\ConnectXP\ConnectXP.exe"`.
Допустимы также `/DIconFile="..."` и `/DNoticesFile="..."`.
Результат: `output\ConnectXP-1.0.0-Setup-x86.exe`.

**Кодировка:** оба ISS-файла и `licenses\license_*.txt` — Windows-1251,
без BOM, с CRLF. Редактируйте их в этой кодировке, чтобы сохранить русский
текст в ANSI-компиляторе. Английская версия условий использует ту же кодировку.

## Поведение

- Установка для текущего пользователя, по умолчанию в
  `%LOCALAPPDATA%\Programs\ConnectXP`, с выбором другой папки.
- Windows XP SP3 x86 и более новые x86/x64 Windows; приложение остаётся 32-битным.
- Русский и английский интерфейс установщика. Язык приложения задаётся только
  при отсутствии сохранённого значения; существующий выбор не перезаписывается.
- Ярлык в меню «Пуск» создаётся всегда. Рабочий стол и автозапуск в трее —
  дополнительные задачи, изначально выключенные. Если автозапуск уже включён,
  задача выбирается автоматически, а путь обновляется на установленную копию.
- Перед установкой/удалением нужно выйти из приложения через меню трея.
  Установщик не завершает передачу файлов принудительно.
- Нет проверок или установки .NET, VC++ Runtime и дополнительных DLL,
  регистрации COM, Active Setup или изменений брандмауэра. Внешние зависимости
  CopilotXP удалены; сетевой доступ разрешается средствами Windows.
- Существующие данные `%APPDATA%\Connect95` и `HKCU\Software\Connect95`
  используются без переноса. Это реальные имена хранилищ ConnectXP 1.0.
- При удалении данные сохраняются по умолчанию. Отдельная отметка очищает
  известные файлы идентификатора, сопряжений и истории и ключ настроек только
  текущего пользователя. Неизвестные файлы и подпапки сохраняются.
  При тихом удалении профиль сохраняется.
- Полученные файлы в «Моих документах» не удаляются. Автозапуск удаляется
  только если указывает на удаляемую установленную копию.

## Тексты и оформление

Приветствие объясняет основные функции и первое подключение. Условия описывают
сопряжение, локальное хранение, разрешения телефона, удаление и ограничения
версии 1.0. Это пользовательский текст условий использования; отдельная
лицензия на исходный код проекта им не устанавливается. Лицензии cJSON и Mbed
TLS сохраняются в `THIRD-PARTY-NOTICES.txt`.

Тексты можно править в `licenses\license_ru.txt` и `license_en.txt`,
приветствие и завершение — в разделе `[Messages]` основного скрипта.
Условия и уведомления компонентов также устанавливаются рядом с EXE.
Других ассетов для сборки не требуется.

## Проверка комплекта

Проверены наличие исходных файлов, размеры BMP, кодировка Windows-1251/CRLF
и используемые функции по исходному коду Inno Setup 5.6.1.
Полная компиляция и запуск установщика в Windows пока не проверены:
32-битный компилятор аварийно завершается при запуске через Wine в облачной
Linux-среде. Готовый Setup EXE в комплект не включён.
